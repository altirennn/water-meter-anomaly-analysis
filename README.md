# Анализ показаний водосчётчиков

Python-скрипт для расчёта суточного расхода из накопительных показаний и поиска аномалий.

Исходные файлы задания помещаются в `data/source/`. Они не включены в репозиторий.

План решения:
1. Проверить и отсортировать показания по прибору и дате.
2. Вычесть соседние накопительные показания, не заполняя пропуски дат.
3. Добавить правила для аномалий и сопоставить их с событиями.
4. Сохранить расчёты и сводки в CSV.

Результаты и точные пороги будут добавлены после формирования расчёта.
