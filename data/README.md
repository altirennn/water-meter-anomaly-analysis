# Исходные данные

Распакуйте архив задания в эту папку так, чтобы три файла лежали в `data/source/`:

- `pokazaniya.csv` — накопительные показания и число пакетов за сутки;
- `pribory.csv` — модель прибора и дополнительные поля;
- `sobytiya.csv` — события, зарегистрированные приборами.

Исходный архив в репозиторий не включён. CSV в `data/source/` добавлены в `.gitignore`.
